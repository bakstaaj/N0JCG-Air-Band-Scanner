# N0JCG Air Band Scanner v1.0.1

## Release highlights

- Registration remains active after the signed lease expiration time.
- Air Band Scanner does not require periodic license refreshing after activation.
- Background and explicit license refresh calls are disabled for this product.
- Added regression coverage for persistent registered operation.
- Includes the standard header documentation and Raspberry Pi deployment support.

## Compatibility

- RTL-SDR EEPROM serial: `00000118`
- Product ID: `n0jcg-air-band-scanner`
- License prefix: `N0JCG-ABS-`
