# N0JCG Air Band Scanner v1.0.0

## Release highlights

- Added the standard N0JCG responsive footer with release version and product links.
- Added the `/VERSION` endpoint used by the footer version display.
- Added the reusable Raspberry Pi deployment script at `deploy/deploy-to-pi.sh`.
- Includes the standalone receive-only Airband scanner, FFT-directed tuning, FAA radius search, airport-code lookup, squelch controls, channel pause/block controls, registration, five-minute trial, and standard PDF user guide.

## Hardware

- RTL-SDR EEPROM serial: `00000118`
- Civil Airband: `118.000–136.975 MHz`
